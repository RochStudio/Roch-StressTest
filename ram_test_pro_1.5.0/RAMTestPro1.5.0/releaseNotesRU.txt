RAM Test Pro 1.5.0. Список изменений.

Тест памяти:
    - Больше не требуется обязательный запуск от имени администратора (но рекомендуется);
    - Добавлены скроллбары в блоки информации о железе;
    - Добавлена поддержка многосокетных и односокетных NUMA-систем (серверы и рабочие станции);
    - Добавлена поддержка Больших Страниц памяти, актуальная для серверных систем;
    - Исправлено автоопределение объема памяти при очень малом или очень большом объеме ОЗУ;
    - Оптимизирована автоматическая аллокация памяти;
    - Добавлена красная подсветка при ошибке;
    - Уменьшен размер файла RAM Test Pro.exe (оптимизация зависимостей);
    - Оптимизированы тестовые функции и добавлены новые (бета);
    - Добавлены тени для окон;
    - Исправлен баг при повторном запуске программы;
    - Исправлен краш программы при перезагрузке пк;
    - Исправлено определение версии Windows;
    - Исправлено определение объема модулей памяти более 32 ГБ;
    - Исправлена ошибка с определением путей к конфигам;
    - и другие мелкие изменения.

Бенчмарк:
    - Теперь бенчмарк поддерживает многосокетные и NUMA системы. Можно выбрать тестируемый сокет, при этом NUMA узлы выбираются автоматически;
    - Добавлены фильтры результатов для точных многократных измерений;
    - При открытии бенчмарка можно переключаться на основное окно с тестом;
    - Алгоритмы тестирования переработаны и улучшены;
    - Добавлена функция автоматического перезапуска бенчмарка с сохранением скриншота каждого прогона;
    - Улучшено качество скриншотов;
    - Исправлена редкая ошибка аллокации памяти;
    - Во время длительных прогонов бенчмарка экран больше не гаснет;
    - и другие мелкие изменения.
